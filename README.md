# 名片夾 bizcard

個人名片管理 PWA：拍照辨識單張或多張名片（Claude / Gemini），資料存在自己的 Google Sheets 與 Drive。

- 規格文件：[`docs/`](docs/)（從 [docs/README.md](docs/README.md) 開始）
- 開發守則：[`CLAUDE.md`](CLAUDE.md)
- 部署步驟：[`docs/08-部署與設定.md`](docs/08-部署與設定.md)

> 本 repo 為公開 repo，不含任何金鑰、部署網址或真實名片資料。

## JC 操作手冊

### 第一次設定（約 30 分鐘，只需做一次）
詳細步驟見 [`docs/08-部署與設定.md`](docs/08-部署與設定.md)，摘要如下：

1. **後端**：新增一份試算表「名片夾資料庫」→「擴充功能 → Apps Script」→ 貼上 `gas/dist/Code.gs` 與 `gas/appsscript.json`。後端只會取得這份試算表與自己建立的 Drive 資料夾的權限。
2. 在 Apps Script 編輯器執行 `setup()`（第一次會要求授權），再執行 `generateToken()`，把產生的權杖記到「專案設定 → 指令碼屬性」的 `APP_TOKEN`。
3. 同一處加入 `ANTHROPIC_API_KEY`、`GEMINI_API_KEY` 等屬性（金鑰只放這裡，不要貼到聊天或 GitHub）。
4. 「部署 → 新增部署作業 → 網頁應用程式」，執行身分「我」、存取權「任何人」，複製部署網址。
5. **前端**：repo 的 Settings → Pages → Source 選「GitHub Actions」。合併到 `main` 後會自動部署到 `https://<GitHub 帳號>.github.io/bizcard/`。
6. **手機**：用 Pixel 8 的 Chrome 開啟上述網址 →「⋮」選單 →「安裝應用程式」。打開 App →「設定」→ 貼上部署網址與權杖 → 按「測試連線」，看到「連線成功」即可。

### 日常使用
| 想做的事 | 操作 |
|---|---|
| 掃名片 | 下方「掃描」→「拍照」或「從相簿選擇」（可一次選多張照片，每張照片可有多張名片） |
| 修正辨識結果 | 確認頁拖曳框的四角調整範圍；黃色欄位是 AI 沒把握的，請特別確認 |
| 名片有背面 | 確認頁該張名片按「加拍背面」，兩面不同的欄位會請你選 |
| 一批名片同一個場合 | 確認頁上方「整批設定」填標籤、場合、日期，會套用到這次所有名片 |
| 遇到已存在的人 | 儲存時會跳出「疑似已存在的聯絡人」，選合併（舊職稱自動記入歷程）或新增 |
| 找人 | 首頁搜尋框可搜姓名、公司、電話（09 開頭也可以）、Email、標籤；點「依公司」可分組 |
| 打電話、寄信、導航 | 打開聯絡人，按上方的撥號／寄信／地圖／LinkedIn 按鈕 |
| 對方升遷或換公司 | 聯絡人頁按「編輯」改職稱，勾選「這是職稱或公司異動」，舊職稱會留在時間軸 |
| 沒有網路時 | 照常拍照與編輯，會先存在手機，連上網路後自動送出 |
| 在電腦上整理 | 直接開 Google Drive 的「名片夾」試算表修改，手機下次開啟時會同步 |
| 看費用 | 「設定」→「查詢用量」，顯示本月辨識次數與估計費用（美元） |

### 更新後端程式
把新版 `gas/dist/Code.gs` 貼到 Apps Script（或 `cd gas && npx clasp push`），再到「部署 → 管理部署作業 → 編輯 → 版本：新版本」，網址不會變，手機不用重設。

### 常見問題
- **每次開啟都要重新輸入網址與權杖**：你可能是從 LINE 等 App 點連結，在內建瀏覽器裡開啟。請改用 Chrome 開啟並「安裝應用程式」，之後從主畫面圖示開啟。
- **測試連線顯示「權杖錯誤」**：確認手機上的權杖和指令碼屬性 `APP_TOKEN` 完全相同（沒有多餘空白）。連續錯 20 次會暫停 1 小時。
- **辨識很慢或失敗**：確認金鑰仍有效、帳戶有餘額；設定頁可暫時改用另一家引擎。
- **換手機**：在新手機重新安裝並輸入網址與權杖即可，資料都在 Google Sheets 與 Drive。
