# 01 需求規格

## 1. 目標與使用者
- 唯一使用者：JC（普瑞默生技），在 Pixel 8 上使用；偶爾在電腦上直接看 Google Sheets。
- 名片特性：中英混排、繁體中文為主，常見台灣格式電話（+886、02-xxxx-xxxx#分機）、雙面名片（一面中文一面英文）。
- 典型情境：展會或會議後一次收到 5–20 張名片，排在桌上拍 1–3 張照片批次匯入；平時單張隨手拍。

## 2. 功能需求

### F1 取得影像
- F1.1 直接開相機拍照（`<input type="file" accept="image/*" capture="environment">`）。
- F1.2 從相簿選一張或多張圖片（`multiple`）。
- F1.3 上傳前在手機端縮圖：長邊最多 2400px、JPEG 品質 0.85，並依 EXIF 方向轉正。
- F1.4 支援旋轉 90° 按鈕（AI 辨識前可手動轉正）。

### F2 辨識（單張或多張）
- F2.1 一張照片送後端一次，回傳 0..N 張名片的結構化欄位與位置框（見 docs/05）。
- F2.2 照片中沒有名片時，顯示「未偵測到名片」並可重拍。
- F2.3 可在設定頁選擇辨識引擎：Claude / Gemini；另有「比較模式」同時送兩家並並列顯示結果（驗收與調校用）。
- F2.4 辨識中顯示進度；失敗時顯示原因並可重試，原圖不遺失。

### F3 確認與修正
- F3.1 辨識後進入確認頁：上方顯示原圖與每張名片的框（編號對應），下方為每張名片的欄位卡片。
- F3.2 框可拖曳四角調整、可刪除誤判的框、可手動新增框（新增框後可對該框單獨重新辨識）。
- F3.3 欄位皆可編輯；信心低的欄位（AI 標示）以醒目顏色提示。
- F3.4 可為某張名片「加拍背面」：拍背面 → 辨識 → 與正面欄位合併（空白欄位補上、衝突欄位讓使用者選）。
- F3.5 可一次為整批名片設定共用的「標籤」與「取得日期」（預設今天）與「場合」（例如 BIO Asia 2026）。
- F3.6 按「儲存」才寫入雲端；未儲存前離開頁面會提示。

### F4 儲存與同步
- F4.1 儲存時：裁切後的單張名片圖與原始照片存到 Drive，欄位寫入 Sheets。
- F4.2 手機端以 IndexedDB 保存聯絡人快取，開啟 App 時與後端做增量同步（以 `updated_at` 為準）。
- F4.3 離線時可拍照，照片排入「待辨識佇列」，恢復連線後自動或手動送出。
- F4.4 在電腦上直接修改 Sheets 的資料，下次同步時手機會取得（後端以 Sheets 為唯一真實來源；Sheets 手動修改時 `updated_at` 由 onEdit 觸發器更新）。

### F5 重複比對與職稱歷程
- F5.1 儲存前，每張新名片與既有聯絡人比對（規則見 docs/03 §5）。
- F5.2 若疑似同一人，顯示差異並讓使用者選：「更新為同一人」或「另存新聯絡人」。
- F5.3 選更新時，若職稱、部門或公司有變動，舊值寫入「職稱歷程」並保留日期；主資料更新為最新值；新舊名片圖都保留。
- F5.4 聯絡人詳情頁顯示職稱歷程時間軸。

### F6 瀏覽與搜尋
- F6.1 清單依「取得日期」新到舊排序，可切換依公司簡稱分組。
- F6.2 全文搜尋（姓名中英、公司全名與簡稱、職稱、Email、電話、標籤、備註），在手機端快取上即時篩選。
- F6.3 標籤篩選。
- F6.4 詳情頁：名片圖（正反面，可放大）、所有欄位、點電話撥號、點 Email 寄信、點網址/LinkedIn 開啟、點地址開地圖。
- F6.5 編輯與刪除（軟刪除，Sheets 標記 `deleted=TRUE`，不實際刪列）。

### F7 設定
- F7.1 後端網址（GAS Web App URL）與存取權杖，存在手機 localStorage。
- F7.2 預設辨識引擎、比較模式開關。
- F7.3 顯示本月辨識次數與估計費用（後端辨識紀錄彙總）。

## 3. 非功能需求
- N1 效能：單張照片從送出到顯示結果 ≤ 15 秒（P90）；含 5 張以上名片的照片 ≤ 30 秒（P90）。
- N2 規模：支援至少 3,000 位聯絡人，清單與搜尋操作 ≤ 300ms。
- N3 隱私：資料只存在 JC 的 Google 帳號（D6 修訂後為公司 Workspace 帳號）與 AI 服務商的 API 處理流程中；使用付費 API 方案（不讓資料被用於訓練）。Drive 檔案不公開分享。
- N4 安全：無有效權杖的請求一律拒絕；repo 不含秘密。
- N5 可用性：Pixel 8 Chrome 可「安裝」為 App；繁體中文介面；單手操作。
- N6 成本：每月 300 張名片以內，AI 費用目標 ≤ NT$300。
- N7 可維護：JC 能在 Sheets 直接看懂與修改資料。

## 4. 範圍外（本版不做）
- 匯出 vCard 或同步 Google 聯絡人（D8）。
- 多使用者、分享名片給他人。
- iOS 專屬調整（PWA 本身仍應可在 iOS Safari 運作，但不驗收）。
- CRM 功能（拜訪紀錄、提醒）。
