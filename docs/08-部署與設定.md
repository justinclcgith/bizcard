# 08 部署與設定（JC 操作手冊草稿）

以下步驟需要 JC 本人登入帳號操作。金鑰與權杖**只貼到 Apps Script 的「指令碼屬性」與手機設定頁**，不要貼到聊天、GitHub 或任何文件。

## 1. 帳號與金鑰
1. **GitHub**：建立公開 repo（建議 `bizcard`），到 [Connect GitHub](https://claude.ai/connect-github) 授權並在 Claude 專案設定中加入此 repo。
2. **Anthropic API**：到 Claude Console 建立 API 金鑰，開通付費並設定每月花費上限（建議 US$20）。
3. **Gemini API**：到 Google AI Studio 建立金鑰，所屬 Google Cloud 專案需啟用計費；在 Cloud Console 設定預算警示（建議 US$10）。

## 2. 後端（Google Apps Script，綁定在試算表上）
後端程式要從試算表裡建立，這樣它只能存取這一份試算表與自己建立的 Drive 資料夾（docs/02 §4）。

1. 到 Google 雲端硬碟新增一份試算表，命名為「名片夾資料庫」。
2. 試算表選單「擴充功能 → Apps Script」，把專案改名為「名片夾後端」。
3. 程式碼：把 `gas/dist/Code.gs`（`node gas/tools/bundle.mjs` 產生的單一檔案）整份貼到預設的 `程式碼.gs`。
   - 進階做法：clasp。`clasp create --type sheets --parentId <試算表 ID>` 或 `clasp clone`，`.clasp.json` 不提交，再 `clasp push`。
4. ⚙️ 專案設定勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」，把 `gas/appsscript.json` 的內容貼上覆蓋。
5. 在編輯器執行一次 `setup()` 並授權。授權畫面只會列出：這份試算表、程式建立的 Drive 檔案、連線外部服務。若出現「所有雲端硬碟檔案」或「所有試算表」，代表 appsscript.json 沒貼好。
6. 執行 `generateToken()`，從執行記錄複製權杖。
7. 專案設定 →「指令碼屬性」新增：
   | 屬性 | 值 |
   |---|---|
   | APP_TOKEN | 上一步產生的權杖 |
   | ANTHROPIC_API_KEY | Anthropic 金鑰 |
   | GEMINI_API_KEY | Gemini 金鑰 |
   | CLAUDE_MODEL | `claude-opus-5-5`（預設值，可不填） |
   | CLAUDE_EFFORT | `low`（預設值，可不填） |
   | GEMINI_MODEL | `gemini-3.8-flash`（2026-11 查證） |
   | DEFAULT_PROVIDER | 驗收前 `claude`，驗收後依報告 |
   | PRICE_CLAUDE_IN / PRICE_CLAUDE_OUT | 4 / 20 |
   | PRICE_GEMINI_IN / PRICE_GEMINI_OUT | 0.75 / 3.75（2027-01-01 起 1.5 / 7.5） |
   （DRIVE_FOLDER_ID 由 setup() 自動寫入）
8. 部署 → 新增部署作業 → 類型「網頁應用程式」→ 執行身分「我」、存取權「任何人」→ 複製網址。
   - 公司 Workspace 帳號若沒有「任何人」選項，代表管理員限制了對外分享，需請管理員在 Admin Console 允許 Apps Script 網頁應用程式對外開放，否則手機 App 無法連線。
9. 之後更新：貼上新的 Code.gs → 部署 → 管理部署作業 → 編輯 → 版本選「新版本」（網址不變）。

## 3. 前端（GitHub Pages）
1. repo Settings → Pages → Source 選「GitHub Actions」。
2. 合併到 main 後自動部署，網址為 `https://<GitHub 帳號>.github.io/bizcard/`。

## 4. 手機
1. Pixel 8 Chrome 開啟上述網址 → 選單 →「安裝應用程式」。
2. 開啟 App → 設定 → 貼上 GAS 網址與 APP_TOKEN → 按「測試連線」。
   - 也可先把部署網址（/exec 結尾）填入指令碼屬性 `WEBAPP_URL`，再在 Apps Script 編輯器執行 `showSetupInfo()`，從執行記錄複製 `{"url":…,"token":…}` 這一行，傳到手機（例如存到自己的 Google Keep），在設定頁按「從剪貼簿貼上設定」。
   - 設定頁也能掃描內容為同樣 JSON 的 QR code（需自行產生，請勿用線上 QR 產生器，以免權杖外流）。

## 5. 備份
- Google Sheets 有版本記錄；另建議每月由 GAS 時間觸發器把 Contacts 匯出一份 CSV 到 `名片夾/backup/`（P6 選做）。
