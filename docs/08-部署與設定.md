# 08 部署與設定（JC 操作手冊草稿）

以下步驟需要 JC 本人登入帳號操作。金鑰與權杖**只貼到 Apps Script 的「指令碼屬性」與手機設定頁**，不要貼到聊天、GitHub 或任何文件。

## 1. 帳號與金鑰
1. **GitHub**：建立公開 repo（建議 `bizcard`），到 [Connect GitHub](https://claude.ai/connect-github) 授權並在 Claude 專案設定中加入此 repo。
2. **Anthropic API**：到 Claude Console 建立 API 金鑰，開通付費並設定每月花費上限（建議 US$20）。
3. **Gemini API**：到 Google AI Studio 建立金鑰，所屬 Google Cloud 專案需啟用計費；在 Cloud Console 設定預算警示（建議 US$10）。

## 2. 後端（Google Apps Script，個人帳號）
方式 A（建議）：clasp
1. 電腦安裝 Node.js，執行 `npm i -g @google/clasp`、`clasp login`（用個人 Google 帳號）。
2. 到 https://script.google.com/home/usersettings 開啟「Google Apps Script API」。
3. 在 repo 的 `gas/` 執行 `clasp create --type standalone --title "名片夾後端"`，產生的 `.clasp.json` 不提交。
4. `clasp push` 推送程式碼。

方式 B：手動
1. 在 script.google.com 新增專案，把 `gas/dist/Code.gs`（由 `node gas/tools/bundle.mjs` 產生的單一檔案）整份貼到預設的 `程式碼.gs`。
2. 專案設定勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」，把 `gas/appsscript.json` 的內容貼上覆蓋。

共通設定：
1. 在編輯器執行一次 `setup()`，授權 Sheets、Drive、外部連線權限。
2. 專案設定 →「指令碼屬性」新增：
   | 屬性 | 值 |
   |---|---|
   | APP_TOKEN | 執行 `generateToken()` 產生的 40 字元字串 |
   | ANTHROPIC_API_KEY | Anthropic 金鑰 |
   | GEMINI_API_KEY | Gemini 金鑰 |
   | CLAUDE_MODEL | `claude-opus-5-5` |
   | CLAUDE_EFFORT | `low` |
   | GEMINI_MODEL | `gemini-3.8-flash`（2026-11 查證） |
   | DEFAULT_PROVIDER | 驗收前 `claude`，驗收後依報告 |
   | PRICE_* | 見 docs/05 §7 |
   （SHEET_ID、DRIVE_FOLDER_ID 由 setup() 自動寫入）
3. 部署 → 新增部署作業 → 類型「網頁應用程式」→ 執行身分「我」、存取權「任何人」→ 複製網址。
4. 之後更新：部署 → 管理部署作業 → 編輯 → 版本選「新版本」（網址不變）。

## 3. 前端（GitHub Pages）
1. repo Settings → Pages → Source 選「GitHub Actions」。
2. 合併到 main 後自動部署，網址為 `https://<GitHub 帳號>.github.io/bizcard/`。

## 4. 手機
1. Pixel 8 Chrome 開啟上述網址 → 選單 →「安裝應用程式」。
2. 開啟 App → 設定 → 貼上 GAS 網址與 APP_TOKEN → 按「測試連線」。
   - 也可在 Apps Script 編輯器執行 `showSetupInfo()`，從執行記錄複製 `{"url":…,"token":…}` 這一行，傳到手機（例如存到自己的 Google Keep），在設定頁按「從剪貼簿貼上設定」。
   - 設定頁也能掃描內容為同樣 JSON 的 QR code（需自行產生，請勿用線上 QR 產生器，以免權杖外流）。

## 5. 備份
- Google Sheets 有版本記錄；另建議每月由 GAS 時間觸發器把 Contacts 匯出一份 CSV 到 `名片夾/backup/`（P6 選做）。
