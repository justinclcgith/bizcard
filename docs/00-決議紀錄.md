## 由規劃者在規格內決定的技術細節（非 JC 決議，可調整）
- 前端框架：Vite + TypeScript + Preact + vite-plugin-pwa（輕量、Claude Code 熟悉）。
- 前後端驗證：共用存取權杖（APP_TOKEN），因 GAS Web App 需設為「任何人」才能被 PWA 跨網域呼叫。
- Claude 預設模型 `claude-opus-5-5`；Gemini 預設模型 `gemini-3.6-flash`（P0 時確認 Google 當下的正確模型 ID）。兩者皆可在 Script Properties 改。
